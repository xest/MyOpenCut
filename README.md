# MyOpenCut

**100% 브라우저(클라이언트)에서 동작하는 무료 웹 영상 편집기** (서버 비용 \$0 · [OpenCut](https://github.com/opencut-app/opencut) 기반 커스텀 포크)

별도의 백엔드 서버나 업로드 없이 브라우저 내에서 바로 컷 편집, 멀티 레이어 캡션, 다이내믹 텍스트, 배경음악 페이드, 썸네일 생성, FHD MP4 내보내기까지 처리할 수 있습니다.

---

## 주요 기능

### 1. 2.7K / 4K → FHD (30fps) 편집 & 내보내기
- **16:9 가로(1920×1080)** 및 **9:16 숏폼(1080×1920)** 동시 지원
- 네이티브 `<video>` 하드웨어 디코딩 미리보기 + WebCodecs / Canvas 기반 FHD 30fps MP4 고속 내보내기
- 저장 위치와 파일명을 직접 지정하는 시스템 저장 다이얼로그(`showSaveFilePicker`) 지원
- 미리보기 화면 드래그로 영상 위치(Pan X/Y) 및 확대/축소 조절
- **세이프존(Safe Zone)** 및 **중앙 가이드선(가로·세로)** 토글 (UI 설정 `localStorage` 자동 저장)

### 2. 멀티 레이어 캡션 & 다이내믹 텍스트
- **멀티 레이어 트랙**: 동시간대 캡션 추가 시 빈 레이어에 자동 배치, 타임라인 상하 드래그 또는 인스펙터에서 레이어 이동 가능
- **드래그 길이 조절 & 마그네틱 스냅**: 캡션 좌/우 경계 드래그 시 모든 비디오·캡션 경계 및 재생헤드에 자석 스냅 + 가이드선 표시
- **워드 스타일 부분 색상 지정**: 입력창에서 원하는 단어/구간만 드래그 선택해 색상 변경 가능
- **정렬 · 외곽선 · 세이프존 보정**: 가로/세로 정렬 프리셋, 숫자 직접 입력, 글자 크기의 10% 외곽선 자동 유지, 여러 줄 입력 시 세이프존 내부 자동 클램핑
- **다이내믹 텍스트**: 화면 전체 크기 · 정중앙 기본 배치, **축소(Shrink) / 확대(Grow)** 트랜지션, 유지 시간(슬라이더·직접 입력), **세이프존 9분할 시작/마지막 위치 선택**, 종료 후 **그대로 유지 / 페이드아웃** 선택 지원

### 3. 타임라인 다중 선택 · 연동 편집 · 프리미어 프로 단축키
- **마키(박스) 다중 선택 & 일괄 수정**: 타임라인 빈 공간 드래그(또는 `Shift + 클릭`)로 여러 비디오/캡션 클립을 선택해 동시 이동·복사·삭제 및 인스펙터 일괄 수정 지원
- **영상-캡션 연동 편집**: `왼쪽 자르기(Q)`, `오른쪽 자르기(W)`, `분리하기(Ctrl+K)`, `클립 사이 공백 제거` 시 비디오와 캡션이 함께 연동 이동·분할·트림
- **복사 · 붙여넣기**: `Ctrl+C` / `Ctrl+V` 및 `Alt + 드래그` 클립 복제
- `Space` / `J` / `K` / `L` 재생 제어, `←`/`→` 프레임 이동, `↑`/`↓` 클립 경계 이동, `T` 캡션 추가, `Ctrl+M` FHD 내보내기, `Ctrl+Z`/`Ctrl+Shift+Z` 실행 취소/다시 실행

### 4. 배경 음악 & 현재 프레임 썸네일 생성기
- **배경 음악**: 전체 영상 길이 기준 자동 루프·트리밍 및 페이드 인/아웃 적용
- **썸네일 생성기**: 한 화면 컴팩트 레이아웃, 배경 20% 딤(Dim), 대체 텍스트 부분 색상 지정, 세이프존 꽉 채우기 / 9분할 배치, PNG/JPG 저장

### 5. 프로젝트 저장 / 불러오기 & 자동 저장
- `.myopencut.json` 프로젝트 파일 저장 다이얼로그 및 불러오기 지원
- `IndexedDB` 자동 저장 및 원본 미디어 파일명·크기 기준 재연결 복원

> **참고 (녹음된 음악 제거 AI)**: 브라우저 온디바이스 `Kim_Vocal_2.onnx` 분리 + 바벨·충격음 보존 기능 코드는 내장되어 있으며, Web Worker 백그라운드 오프로드 개선 전까지 UI는 임시 비활성화(`ENABLE_AI_MUSIC_REMOVAL_UI = false`) 상태입니다.

## 로컬 실행 방법

```bash
npm --prefix apps/web install
npm --prefix apps/web run dev
```

브라우저에서 `http://localhost:5173/editor` 로 접속하면 바로 편집할 수 있습니다.

### 테스트 및 빌드

```bash
npm --prefix apps/web test
npm --prefix apps/web run build
```
